Objective: Write a statistical learning algorithm that calibrates an analog sensor, learns the "baseline," and triggers an alert if the data spikes abnormally.

Step 1: Set up Adafruit IO
Open your Adafruit IO Dashboard.
Create a new block: Select the Indicator (it looks like a glowing light bulb).
Create a new feed named factory-alarm. Link it.
Set "On Condition" to = ON (Color: Red).
Set "Off Condition" to = OFF (Color: Green).

Phase 2 (Monitoring): Once it says "MONITORING MACHINE HEALTH", gently wiggle the slider just a little bit left and right. Notice that nothing happens. The machine ignores small noise!
